Methodology

AI Engine & Algorithms

A robust pipeline built on Gradient Boosting and Graph Theory.

🤖

LightGBM Model

Selected for high efficiency on tabular data and ability to handle large datasets. Trained on rolling aggregate features.

🔗

Graph Algorithms

Connected Components & Degree Centrality are used to identify nodes acting as hubs in fraud rings.

⚖️

Data Balancing

Handles class imbalance using class_weight='balanced' to ensure rare fraud cases are detected.
